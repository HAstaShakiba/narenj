نارنجNarenj

فایل را روی چرخ بکشید و یکی از قاچ‌ها را انتخاب کنید. تبدیل، کم‌حجم کردن، کوتاه کردن، باز کردن فایل فشرده: ویدیو، صدا، عکس، PDF، سند و فایل فشرده، همه روی کامپیوتر خودتان. رایگان و متن‌باز، مثل Tangerine برای مک، ولی روی ویندوز و لینوکس هم.

سه چرخ، یک حرکت

موقع کشیدن فایل Shift، Ctrl یا Alt را نگه دارید، یا فایل را روی یکی از تب‌های بالای چرخ نگه دارید؛ قاچ‌ها قبل از رها کردن فایل عوض می‌شوند.

تبدیل Shift

تبدیل فایل به فرمتی دیگر. چرخ فقط فرمت‌هایی را نشان می‌دهد که به فایل می‌خورند.

ابزارها Ctrl

کم‌حجم کردن، کوتاه کردن، تغییر اندازه، چرخاندن، باز کردن فایل فشرده؛ فرمت فایل عوض نمی‌شود.

کارها Alt

باز کردن، نشان دادن در پوشه، کپی مسیر، زیپ کردن، چسباندن چند فایل به هم یا انداختن در سطل زباله.

هر فایلی که رویش بیندازید

نتیجه کنار فایل اصلی با اسمی روشن ذخیره می‌شود و هیچ فایلی را بازنویسی نمی‌کند. هر قاچ فقط وقتی نشان داده می‌شود که ابزار لازمش نصب باشد.

شیشه‌ای که جا می‌افتد

تم روشن و تیره، و شیشه‌ی شفاف، معمولی یا کدر. کلیک‌های اطراف چرخ به پنجره‌های زیرش می‌رسند.

یک میان‌بر

Ctrl Alt N چرخ را از هر جایی نشان می‌دهد و پنهان می‌کند. در تنظیمات می‌توانید عوضش کنید.

پیشرفت روی خود چرخ

⎋

با کیبورد هم

با کلیدهای جهت قاچ را انتخاب کنید، Enter اجرایش می‌کند و Esc فایل را پاک می‌کند.

جایگزین رایگان Tangerine برای ویندوز و لینوکس

Tangerine و FanDrop تبدیل فایل را به سادگی کشیدنش روی یک چرخ کردند، ولی فقط روی مک. نارنج همین حرکت را به ویندوز ۱۰ و ۱۱، لینوکس (اوبونتو، دبیان و دسکتاپ‌های گنوم) و مک می‌آورد، رایگان.

نصب

نسخه‌ی 1.4.0. نسخه‌های قبلی در صفحه‌ی ریلیزها هستند.

ویندوز ۱۰ و ۱۱

  1. narenj-1.4.0-setup.exe را دانلود کنید و اجرایش کنید. برای کاربر خودتان نصب می‌شود، بدون دسترسی ادمین، و پایتون، GTK و ffmpeg را هم همراه دارد.
  2. Ctrl Alt N را بزنید تا چرخ باز شود؛ دوباره بزنید تا بسته شود.
  3. برای سند، اسلاید و صفحه‌گسترده LibreOffice و برای Markdown و EPUB pandoc را نصب کنید؛ نارنج خودش پیدایشان می‌کند.

مک با تراشه‌ی اپل

  1. narenj-1.4.0-macos.dmg را دانلود کنید، بازش کنید و نارنج را به پوشه‌ی Applications بکشید.
  2. برنامه با Developer ID اپل امضا نشده، پس بار اول به System Settings › Privacy & Security بروید و Open Anyway را بزنید، یا این را اجرا کنید: 
    xattr -dr com.apple.quarantine /Applications/Narenj.app
  3. تا وقتی نارنج باز است، Control Option N چرخ را نشان می‌دهد و پنهان می‌کند.

اوبونتو ۲۲٫۰۴ به بعد و دبیان، از مخزن apt

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://hastashakiba.github.io/narenj/narenj-archive-keyring.gpg | sudo tee /etc/apt/keyrings/narenj.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/narenj.gpg] https://hastashakiba.github.io/narenj stable main" | sudo tee /etc/apt/sources.list.d/narenj.list
sudo apt update && sudo apt install narenj
narenj --setup

یک بار از حساب کاربری خارج و دوباره وارد شوید تا افزونه‌ی گنوم که چرخ را همیشه رو نگه می‌دارد بارگذاری شود. آپدیت‌ها با sudo apt upgrade می‌رسند.

مک با Homebrew (تراشه‌ی اپل و اینتل)

brew tap hastashakiba/narenj https://github.com/HAstaShakiba/narenj
brew install narenj
narenj

Homebrew خودش GTK، پایتون، ffmpeg، pandoc و poppler را نصب می‌کند. برای فایل‌های آفیس brew install --cask libreoffice را هم اجرا کنید.

پرسش‌ها

آیا Tangerine نسخه‌ی ویندوز یا لینوکس دارد؟

Tangerine فقط برای مک ساخته شده است. نارنج همان روش را دارد، یعنی کشیدن فایل روی چرخی از تبدیل‌ها، و روی ویندوز ۱۰ و ۱۱، لینوکس (اوبونتو، دبیان و دسکتاپ‌های گنوم) و مک اجرا می‌شود.

نارنج رایگان است؟

بله. نارنج رایگان و متن‌باز با مجوز MIT است؛ بدون حساب کاربری، بدون محدودیت و بدون تبلیغ.

نارنج فایل‌هایم را جایی آپلود می‌کند؟

نه. همه‌ی تبدیل‌ها روی کامپیوتر خود شما با ffmpeg، LibreOffice، pandoc و poppler انجام می‌شود و به اینترنت نیازی ندارد.

نارنج چه فرمت‌هایی را تبدیل می‌کند؟

ویدیو (MP4، MOV، MKV، WebM، GIF)، صدا (MP3، M4A، WAV، FLAC، OGG، Opus)، عکس (PNG، JPG، WebP، BMP، TIFF، ICO، SVG)، PDF، سند (DOCX، ODT، RTF، TXT، Markdown، HTML)، اسلاید، صفحه‌گسترده، EPUB، زیرنویس (SRT، VTT، ASS) و فایل فشرده (ZIP، TAR، GZIP، RAR، 7z). فهرست کامل را ببینید.

نارنج با Tangerine یا FanDrop ارتباطی دارد؟

نه. نارنج پروژه‌ای مستقل است که از آن‌ها الهام گرفته و با سازندگانشان ارتباطی ندارد.

با الهام از Tangerine و FanDrop برای مک. نارنج پروژه‌ای مستقل است و با آن‌ها ارتباطی ندارد. مجوز MIT · کد منبع در گیت‌هاب
