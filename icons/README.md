# Icons

The symbolic icons on Narenj's wedges, copied from the GNOME
[Adwaita icon theme](https://gitlab.gnome.org/GNOME/adwaita-icon-theme) (version 42) so they
show on every system whatever its icon theme or layout. They are licensed under the GNU LGPL v3
