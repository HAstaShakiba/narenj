Narenj

A drag-and-drop ffmpeg wheel for GNOME, Windows and macOS. Latest version: 1.3.0. Source: github.com/HAstaShakiba/narenj

Install on Windows 10 / 11

Download narenj-1.3.0-setup.exe

Run the installer. It installs for your user without admin rights and brings its own Python, GTK and ffmpeg. Press Ctrl+Alt+N to open the wheel and again to close it; change the keys in Start menu › Narenj › Properties › Shortcut key. Older versions are on the releases page.

Install on macOS

Download narenj-1.3.0-macos.dmg (Apple Silicon)

Open it and drag Narenj to Applications. The app is not signed with an Apple Developer ID, so the first time open System Settings › Privacy & Security and click Open Anyway. Control+Option+N shows and hides the wheel. On Intel Macs, or to get updates through Homebrew:

brew tap hastashakiba/narenj https://github.com/HAstaShakiba/narenj
brew install narenj

Install on Ubuntu / Debian

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://hastashakiba.github.io/narenj/narenj-archive-keyring.gpg | sudo tee /etc/apt/keyrings/narenj.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/narenj.gpg] https://hastashakiba.github.io/narenj stable main" | sudo tee /etc/apt/sources.list.d/narenj.list
sudo apt update
sudo apt install narenj
narenj --setup

Then log out and back in once so GNOME Shell loads the always-on-top extension. Updates arrive with sudo apt upgrade.
