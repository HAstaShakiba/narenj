Three wheels, one gesture

Hold Shift, Ctrl or Alt while you drag, or hover a tab above the wheel, and the wedges change under the file before you let go.

Convert Shift

Turn a file into another format. The wheel only offers what fits the file.

Tools Ctrl

Compress, trim, resize, rotate, extract — the file keeps its format.

Actions Alt

Open, reveal, copy the path, zip, join several files, or trash.

Whatever you drop on it

Results land next to the original with a clear name, and never overwrite anything. A wedge only shows when what it needs is installed.

A free Tangerine alternative for Windows and Linux

Tangerine and FanDrop made converting a file as quick as dragging it onto a wheel, but only on the Mac. Narenj brings the same gesture to Windows 10 and 11, to Linux (Ubuntu, Debian and other GNOME desktops) and to macOS, for free.

⊞

Windows

A one-click installer with everything inside: Python, GTK and ffmpeg. No admin rights needed.

🐧

Linux

An apt repository for Ubuntu and Debian, so updates come with the rest of your system.

⌘

macOS

A drag-to-Applications disk image for Apple Silicon, or Homebrew on any Mac.

Your files never leave your computer

Online converters need your file on their server first. Narenj runs ffmpeg, LibreOffice and friends right where your files already are.

Install

Version @VERSION@. Older versions are on the releases page.

Windows 10 and 11

  1. Download narenj-@VERSION@-setup.exe and run it. It installs for your user, without admin rights, and brings its own Python, GTK and ffmpeg.
  2. Press Ctrl Alt N to open the wheel and again to close it.
  3. For documents, slides and spreadsheets, install LibreOffice; for Markdown and EPUB, pandoc. Narenj finds them.

macOS on Apple Silicon

  1. Download narenj-@VERSION@-macos.dmg, open it and drag Narenj to Applications.
  2. The app is not signed with an Apple Developer ID, so the first time open System Settings › Privacy & Security and click Open Anyway, or run: 
    xattr -dr com.apple.quarantine /Applications/Narenj.app
  3. Control Option N shows and hides the wheel while it runs.

Ubuntu 22.04+ and Debian, from the apt repository

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @URL@/narenj-archive-keyring.gpg | sudo tee /etc/apt/keyrings/narenj.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/narenj.gpg] @URL@ stable main" | sudo tee /etc/apt/sources.list.d/narenj.list
sudo apt update && sudo apt install narenj
narenj --setup

Log out and back in once so GNOME Shell loads the always-on-top extension. Updates arrive with sudo apt upgrade.

macOS with Homebrew (Apple Silicon and Intel)

brew tap hastashakiba/narenj https://github.com/HAstaShakiba/narenj
brew install narenj
narenj

Homebrew brings GTK, Python, ffmpeg, pandoc and poppler. For Office files add brew install --cask libreoffice.

Questions

Is there a Tangerine for Windows or Linux?

Tangerine is a Mac app. Narenj works the same way, dragging a file onto a wheel of conversions, and runs on Windows 10 and 11, Linux (Ubuntu, Debian and other GNOME desktops) and macOS.

Is Narenj free?

Yes. Narenj is free and open source under the MIT license, with no account, no limits and no ads.

Does Narenj upload my files?

No. Every conversion runs on your own computer with ffmpeg, LibreOffice, pandoc and poppler. It works offline.

Which formats can Narenj convert?

Video (MP4, MOV, MKV, WebM, GIF), audio (MP3, M4A, WAV, FLAC, OGG, Opus), images (PNG, JPG, WebP, BMP, TIFF, ICO, SVG), PDF, documents (DOCX, ODT, RTF, TXT, Markdown, HTML), slides, spreadsheets, EPUB, subtitles (SRT, VTT, ASS) and archives (ZIP, TAR, GZIP, RAR, 7z). See the full list.

Is Narenj related to Tangerine or FanDrop?

No. Narenj is an independent project inspired by them; it is not affiliated with their makers.
